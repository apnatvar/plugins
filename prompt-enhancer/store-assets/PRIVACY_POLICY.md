# Prompt Composer Privacy Policy

**Effective date:** July 15, 2026

Prompt Composer is a browser extension published by Brownsmith Dynamics. It is designed to review, format, and reuse prompt text beside compatible editors across the web.

## Information the extension handles

Prompt Composer reads text from the focused supported editor only when a user interacts with an extension feature. This text may include a user's draft prompt or selected text. Processing takes place locally in the browser.

The extension stores the following information in `chrome.storage.local`:

- extension preferences;
- site enablement settings; and
- built-in and user-created snippet definitions.

Users can edit or delete personal snippets, or remove all locally stored extension data by uninstalling the extension.

## Information not collected

Brownsmith Dynamics does not collect, receive, sell, share, or transmit prompt text, editor contents, selected text, snippets, settings, clipboard contents, previews, or undo snapshots.

Prompt Composer has no account system, backend service, analytics, telemetry, advertising, tracking, or model API integration. It does not execute remotely hosted code.

## Drafts and submission

Draft text is processed in page memory and is not persisted. Preview and undo data exist only in memory for the active page. Prompt Composer does not click a website's submit control and does not send prompts on a user's behalf.

## Clipboard

Prompt Composer can write a prepared result to the clipboard only after an explicit user click. It does not request clipboard-read permission and does not collect or store clipboard contents.

## Browser permissions

Prompt Composer uses:

- `storage` to save settings and snippet definitions locally;
- `sidePanel` to provide the management interface; and
- access to HTTP and HTTPS websites so the toolbar can appear beside compatible editors. The extension starts with a curated hostname allowlist; users can add or remove websites or explicitly enable all websites.

The extension does not request browsing history, tabs, identity, or downloads permissions.

## Data sharing and retention

No handled information is sent to Brownsmith Dynamics or a third party. Locally stored settings and snippet definitions remain in the user's Chrome profile until the user changes or deletes them, or uninstalls the extension.

## Limited Use

Prompt Composer's use of information received from browser permissions complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Information is used only to provide and improve the extension's single user-facing purpose.

## Changes

If this policy changes, the effective date above will be updated. Material changes will be disclosed through the extension listing or another appropriate notice.

## Contact

For privacy questions or support, contact Brownsmith Dynamics through https://brownsmithdynamics.com.
