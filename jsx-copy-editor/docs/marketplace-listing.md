## Description

Edit supported literal JSX text from one focused VS Code panel. JSX Copy Editor reads the active JSX or TSX component and statically traverses supported local component imports. Fields are grouped by source file and each field shows its source line, so you can review copy in context before saving.

Choose **Copy Editor: Open** from the Command Palette while a local `.jsx` or `.tsx` file is active. Edit the fields and select **Save Changes** to apply them through a VS Code workspace edit. Changes support normal VS Code undo. The extension reads current document buffers, including unsaved editor contents, and never saves files to disk for you.

Traversal follows static source order and avoids repeated component visits. Dynamic expressions, props, maps, conditionals, template content and attribute values are outside the supported literal-text scope. Stale source selections are rejected before changes are applied.

JSX Copy Editor processes source locally in VS Code. It has no backend, AI service, network calls or telemetry. It is made by [Brownsmith Dynamics](https://brownsmithdynamics.com).
