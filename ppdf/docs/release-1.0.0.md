# PPDF 1.0.0 draft

Prepared on 23 October 2026. High Quality settings are unchanged; Balanced is stronger, and Smallest aggressively reduces eligible JPEG images. UI and runtime icons use company teal. The manifest and package identify version 1.0.0.

The final runtime ZIP was loaded directly from its extracted contents in isolated Chromium. Generated-example results, public URL checks, screenshot provenance, artifact inventory, the SHA-256 and remaining Store submission steps are recorded in [the draft handoff](../release/READINESS.md) and [verification.json](../release/verification.json). Full regression tests were not rerun and no commit was made.
