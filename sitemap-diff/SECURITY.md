# Security policy

## Supported versions

Until a stable version is released, security fixes are handled on the current development branch. After a release, report issues against the latest supported release and current development branch.

## Reporting a vulnerability

Please do not publish exploit details in a public issue. Email [contact@brownsmithdynamics.com](mailto:contact@brownsmithdynamics.com) with the package version, Node.js version, a short description, and a minimal reproduction that contains no private sitemap URLs or data. If you cannot safely share a reproduction, describe the affected code path instead.

Do not send credentials, access tokens, customer URLs, or private sitemap contents. We will acknowledge reports and coordinate a fix and disclosure timeline with the reporter.

See the [security assessment](docs/security-assessment.md) for the current trust boundaries and limits. The assessment is based on local source review dated 2026-10-23 and must be updated before release.
